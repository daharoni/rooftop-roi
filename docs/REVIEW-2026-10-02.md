# Rooftop ROI: public-launch review (2026-10-02)

Six independent reviewers (three Opus 5.5, three Sonnet 5.5) each took one lens: core
simulation and money math, data ingestion and physical models, application layer, security
and privacy, tests and tariff data, product and monetization. Every bug marked **confirmed**
was reproduced with a node script or in a Playwright browser session; nothing in the repo
was modified. Baseline: 240 tests pass, the tariff validator passes with one warning, and the
committed worker bundle is byte-identical to a fresh build.

**Verdict.** The core is unusually rigorous for a side project: battery physics, NBT export
caps, true-up ordering, DST handling, the wealth-vs-market identity and the worker
architecture all check out. What is not ready is everything that assumed the author's own
house: parsers tuned to one SCE file, an EV detector fitted to one charger, SCE constants
applied to PG&E and SDG&E, a weather cache that never writes, and a privacy page that
undercounts the network calls. Fix the P0 list below and this is a credible public beta.

## P1: correctness bugs (wrong by degree, not kind)

**Money math** (`core/finance.js`, `core/engine.js`)
- Lease shorter than horizon gives free savings after the term ends (no buyout, no O&M). 15-yr term looks about $10k better than 25-yr. `finance.js:249-259,291-298`.
- ACC Plus adder held flat for 25 years; tariff notes say it expires after the 9-year lock. Overstates NPV $634 at the optimum, $1,369 at 40 panels, and biases the optimizer toward larger arrays. `finance.js:289`, `engine.js:654`.
- `bill -= accPlus` has no floor, so negative monthly bills are paid out as cash at large arrays. `engine.js:654`.
- True-up month defaults to whatever month the data starts (no file sets `nbt.true_up_month`); first month is trued up alone; year-1 savings move about $60-$140 depending on download date. `engine.js:454,658`.
- `plane.costAdder` (Roof tab "Extra cost $") is stored and never reaches finance or the optimizer.
- Engine `buildRates` has its own TOU lookup that ignores `schedule_overrides` and uses a different holiday rule than `tariff.periodAt` (356 hours differ on SDG&E EV-TOU-2). `engine.js:401-446` vs `tariff.js:325-356`.
- Unknown or cross-utility `providerId` silently drops generation charges (PG&E baseline $3,033 vs $5,281). `engine.js:394-398`.
- Export credits can offset non-bypassable charges (small, $4/yr SCE, larger SDG&E). `engine.js:632-641`.
- Inverter and battery replaced only once on horizons over 24 years (`===` at `finance.js:294-295`). Levered IRR returns null when loan term exceeds horizon. `finance.js` default `incentiveMode: "vendor"` differs from app `"none"`; escalation 0.045 vs state 0.05.
- NaN anywhere in a flex `kwhByHour` makes the whole bill NaN. `engine.js:523`.

**Parsers** (`core/greenbutton.js`)
- Partial 15-minute hours summed short and unflagged (10.6% rows dropped gives 10.6% low total, `missing = 0`). `:370-379`.
- Multi-file merge lets a later NaN overwrite real data; `quality.missing` recomputed as 0. `:1099-1110`.
- Generic CSV accepts `Z`/offset timestamps and stores them as local, shifting the whole load 7-8 hours against TOU windows. `:232,1032-1039`.
- Older SCE layout ("X to Y" stamps, 2 columns) fails; generic parser picks the time column as kWh. `:531-534,962-966`.
- Spring-forward day with another gap fills a nonexistent 02:00. `:396-404`.

**Physical models**
- `pv.js:56-63` feeds wind in km/h to an m/s formula, raising output 3.2-3.6%; the SoCal monthly correction masks it only inside a box that also covers Palm Springs and Lancaster. PG&E sites get the uncorrected high bias.
- All-null weather response produces 0 kWh/kW and is cached permanently. `weather.js:348,400-410`.
- Roof geometry: outward normal chosen "away from centroid" is wrong for concave or L-shaped footprints; no self-intersection check; panel dimensions fixed regardless of the `panelW` knob. `app/roof/geometry.js:149,341`.

**App layer** (`app/main.js`, `app/state.js`)
- Stale `ensureSolar` promise still runs `runGrid` against the old worker, so wrong numbers flash after a roof edit. `main.js:~625,~728`.
- Overlapping `bootWorker` calls leak workers. `main.js:130-160`.
- Hash and storage values unvalidated: `panelW=null`, `strat=foo` accepted; number inputs ignore min/max and turn blank into 0. `state.js:229-244`, `app/ui/controls.js:~105`.
- Hash omits default-valued keys and carries no version, so any default change silently alters old links. `fromStorage` ignores `v:1`.
- `addPlane` id collision after deleting a plane (`"p"+(planes.length+1)`).
- `lastDetailKey` survives a worker reboot, so a detail run can be skipped after a utility change.
- Roof tab `mountBuilder` can mount into a detached host if the user leaves during the dynamic import.

## Inefficiencies

- **Weather re-fetch** (P0 #1) is the big one: about 300 Open-Meteo units per site against a 600/minute free limit.
- Full load (17k hours) plus 11 weather years per plane re-cloned to the worker on every tilt or azimuth change, and `E.prepare` re-run. Add a `solar` message; keep `init` for load and tariff.
- `JSON.stringify(simParams())` serialises `Float64Array` flex series as objects: about 200 KB per EV per slider tick. Key on a revision counter.
- `writeHash` and `saveLocal` run on every `State.update` at slider rate (60 Hz). Safari throws SecurityError after about 100 `replaceState` calls in 30 s, and the unguarded throw aborts the subscriber loop. Debounce 300 ms and wrap in try/catch.
- 11 sequential weather requests per site, no 429 backoff, `timeout` error code declared but not implemented.
- Good news: the engine is genuinely off the main thread (zero long tasks during an 8-step slider drag, about 150 ms per grid), stale replies are discarded by request id, and finance re-pricing is about 15 ms without the worker.

## Security, privacy, legal

- No CSP. Leaflet JS and CSS injected without `integrity` or `crossorigin` (`roofBuilder.js:80-83`); Chart.js has SRI. A cdnjs compromise runs in the same origin as the meter data. Recommend vendoring Chart.js, Leaflet and the IBM Plex fonts, then a meta CSP with an explicit `connect-src` allowlist, which makes the privacy promise machine-enforced.
- Google Fonts leaks visitor IP and referer to Google on first load (a known GDPR issue).
- Chart.js CDN failure gives five blank canvases and no message.
- No XSS or prototype-pollution path found; `esc()` is used, `fromHash` uses a static key table.
- "Forget my data" is nearly complete; make the weather store clear explicit and handle `onblocked`.
- **Repo data.** No account numbers, names or street addresses in `data/demo` or fixtures. `docs/data-notes-reference-site.md:19-20` contains `SCE_Usage_8009999999_...csv`; it looks like a placeholder (also a canary in `greenbutton.test.mjs:94`) but confirm. `docs/tariffs-sce.md` ties a bill line to ZIP 91301, and two years of hourly load is a behavioural fingerprint. A second author email appears in commit metadata. Your call whether that is acceptable for your own house.
- **Licences that block an ad-supported site.** Esri World Imagery public tile server is not licensed for commercial use (use USGS NAIP, public domain, or MapTiler/Mapbox/Esri paid). Open-Meteo free tier is non-commercial only and needs a visible CC BY 4.0 link. Nominatim's policy forbids heavy use without identification; the per-tab 1.1 s queue is not per-application. CCPA/CPRA notice and opt-out, Terms, privacy policy, FTC ad disclosure and TCPA consent are all needed once leads or ads exist.
- **What an ad-network script would do:** it runs same-origin with access to localStorage, IndexedDB (meter data, exact roof polygons) and the hash. "Your data never leaves this browser" becomes false the moment it loads. Privacy-preserving alternatives, in order of fit: static sponsored block from the repo; affiliate links with `rel="sponsored"` and no pixel; first-party sponsor rotation chosen client-side by utility; an explicit "Get 3 quotes" opt-in that shows the exact fields before sending. If a network script is non-negotiable, change the headline claim first and isolate it in a cross-origin iframe.
